# Учебная практика: Service Desk

Информационная система учёта заявок и инцидентов технической поддержки.

## Состав решения:
*   **ServiceDesk.Web** — Слой представления (ASP.NET Core MVC). Интерфейс пользователя.
*   **ServiceDesk.Api** — Слой бизнес-логики (ASP.NET Core Web API). Веб-сервис и работа с БД (EF Core + ADO.NET).
